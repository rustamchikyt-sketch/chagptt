# Nova — Telegram-бот на Groq

ChatGPT-подобный бот: стриминг ответов, фото (vision), голосовые (Whisper), история диалога, выбор модели.

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируй токен.
2. Возьми бесплатный ключ на https://console.groq.com/keys
3. Установи и запусти:

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # впиши токен и ключ
python bot.py
```

## Возможности

- Ответы печатаются на глазах (правка сообщения), длинные ответы режутся на части
- Markdown от модели превращается в красивое оформление Telegram: жирный, код с подсветкой, цитаты, списки
- Пришли фото (можно с вопросом в подписи) — бот сам переключится на vision-модель
- Голосовые расшифровываются Whisper и обрабатываются как обычный текст
- Кнопки под ответом: «Заново» и «Новый диалог»
- `/model` — выбор модели (список берётся с Groq), `/system` — своя роль бота, `/new` — сброс контекста
- `ALLOWED_USERS` в `.env` — закрыть бота от посторонних

## Заметки

- История хранится в памяти: после перезапуска бота диалоги очищаются.
- После первой картинки в диалоге используется vision-модель до `/new`.
- Для постоянной работы разверни на VPS через systemd или Docker (`python bot.py` как команда запуска).
